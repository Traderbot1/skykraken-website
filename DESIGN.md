# Design — SkyKraken "Relief & ondes"

The site is a night topographic survey sheet on which radio waves are drawn. Expertise is shown as RF propagating across terrain, not as a radar HUD.

## Palette (assets/style.css `:root`)

| Role | Token | Value |
|---|---|---|
| Ground | `--bg` / `--night` | #0A0E1A / #070A12 |
| Raised surfaces | `--bg-soft`, `--panel` | #0E1322, #141B2C |
| Ink (headings, linework) | `--cream` | #F5F2EA |
| Body text | `--body-c` | #C9CDD6 |
| Secondary text | `--muted` / `--dim` | #9AA3B5 / #7E889B |
| Paper sheets | `--paper` / `--paper-ink` | #EFEADF / #0E1424 |
| Signal (threat, pilot, primary action) | `--accent` / `--accent-bright` | #D23B3B / #EC5B5B |
| Status only | `--green`, `--amber` | #7FD39B, #E9B949 |

Red is reserved: primary buttons, threats, pilots, protected zones. Never decorative.

## Type

- Archivo variable, self-hosted (`assets/fonts`), width axis used as a cartographic device:
  display 112–118 % stretch, weight 720–780; body 100 %, 400.
- `.carto`: 72 % stretch caps, tracked +0.11em — map labels, legends, status, table heads. Never as an eyebrow above a heading.
- JetBrains Mono only for coordinates, frequencies, timestamps, JSON, measurements.

## Components

- Map stage (`[data-terrain]`, src/terrain.js → assets/terrain.js): contour relief shader, RF wavefronts, drone/pilot story, modes `home | mobile | horizon | sk1 | eyes`. Chapters with `data-map="<id>" data-map-mode="…"` steer it. Pause button (WCAG 2.2.2), reduced motion renders one composed still, no WebGL shows `terrain-poster.webp`.
- Legend strip, panels (navy 78 % + blur, 1px cream rule), ledger rows, checks list, specs grid, route (dashed line with stations), arch diagram, paper `.sheet` (outline neatline), `.plate` (product photo on paper, multiply), data sample `<pre>`.
- Buttons: 3px radius, red primary (hover darkens to #B42E2E), ghost with cream rule.
- Hairlines, not cards: sections are separated by 1px rules; no nested cards, no shadows except the paper sheet.

## Motion

One authored moment: the map (camera eases between product framings). GSAP: hero headline lines settle with blur, legend rule draws, panels slide in, route stations stagger, evidence sheet lands. Everything visible without JS and under `prefers-reduced-motion`.

## Shared chrome

Header and footer are generated by `tools/chrome.py` (EN/FR pairs, language switch per page). Edit there, then run `python3 tools/chrome.py`.
